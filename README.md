# GoPlay

---

# Project Pitch
GoPlay is a web app that brings sports fans and players together in one place. Users can explore nearby sports facilities through an interactive map, find available games to join, and connect with other players who share their interests.

--- 

# Features 

- Interactive map to discover sports facilities
- Live geolocation and user positioning
- Discover nearby sports games
- Sports discussion space to connect with players
- Sports quiz game to test knowledge
- User profile with username editing/customization
- Responsive mobile-friendly design
- Modern UI styling using Bootstrap

## How to run the project
### Required installations
1. Software/Languages
- Node.js
- npm
- MongoDB

2. Recommended IDE
- Visual Studio Code

3. Optional Tools
- Git CLI or GitHub

### Required APIs & Keys
- NewsAPI Key

### Installation Order

1. Clone the repo
2. Naviagate to the project
3. Install dependencies (npm install)
4. Create a .env file in the root directory
5. Start MongoDB (node app.js)
6. Open in browser
